# Инструменты замеров

Скрипты лежат в `tools/measure/`. Две задачи: понять, что именно режет оператор, и
подобрать резолвер для туннеля. Выводы, полученные ими, — в [OPERATORS.md](OPERATORS.md)
и [TUNNEL.md](TUNNEL.md).

| Скрипт | Что делает | Где запускать | VPN |
|---|---|---|---|
| `tunnel-speed.py` | **сколько КБ/с даёт текущий резолвер** — главный критерий выбора | телефон, Termux | вкл |
| `operator-probe.sh` | режим фильтрации: белые и небелые сайты, ICMP, UDP, путь по TTL | телефон | выкл |
| `operator-ports.sh` | карта портов до своего VPS и проверка подмены SNI | телефон | выкл |
| `operator-signature.sh` | режут ли по сигнатуре пакета (копия рукопожатия WireGuard) | телефон | выкл |
| `resolver-race.sh` | какие резолверы доносят рекурсию до сервера | ПК + adb | выкл |
| `speed-server.sh` | поднимает раздачу тестовых файлов на сервере | сервер | не важно |
| `phone-bench.sh` | скорость и задержка туннеля, три прогона | ПК + adb | вкл |
| `bottleneck.sh` | разбор канала по пакетам: запросов в секунду, размеры ответов | ПК + adb | вкл |

Список кандидатов в резолверы даёт само приложение (Scan for Working Resolvers), своего
сканера в репозитории нет — порядок описан в [TUNNEL.md](TUNNEL.md).

Адрес сервера и домен скрипты берут из `inventory/hosts.yaml` и
`host_vars/<сервер>/vars.yaml` — по умолчанию первый сервер в инвентаре. Другой —
`HOST=vpn-nl ./скрипт.sh`, разовое переопределение —
`SRV=203.0.113.10 DOMAIN=t2.example.com ./скрипт.sh`.

Для скриптов с adb нужен телефон по USB с включённой отладкой; `tunnel-speed.py` ничего
этого не требует — он работает прямо на телефоне из Termux.

## Чтобы замер не соврал

- **Канал разгоняется около минуты**: первый прогон всегда занижен, брать лучший из трёх.
- **Wi-Fi на телефоне выключить**, иначе замеряется домашний провод. Скрипты печатают
  `wifi_on` в шапке: единица делает замер недействительным.
- Не мерить с компьютера, который сам сидит в этом же туннеле.
- Мерить по одному файлу, а не по случайным сайтам: иначе сравниваешь не резолверы, а
  загруженность чужих серверов. Свою раздачу для этого использовать не выйдет — приложение
  исключает адрес сервера из туннеля, — поэтому берём один и тот же внешний файл,
  `http://cachefly.cachefly.net/1mb.test`.
- Speedtest и подобные приложения не годятся: бьют многими потоками, туннель этого не любит.
- Split tunneling при замерах выключать: системная оболочка adb не входит в список
  выбранных приложений, её трафик пойдёт мимо туннеля и под белым списком умрёт.
- После смены резолвера переподключать VPN, иначе останется старая сессия.

## Эхо-ответчики для диагностики оператора

`operator-*.sh` отличают «фильтр режет» от «на порту никто не слушает» только если на
сервере есть эхо-ответчик. Поднимается временно, вне Ansible:

```bash
systemd-run --unit=probe-tcp --collect socat -v tcp-l:443,fork,reuseaddr system:'echo PROBE-TCP-OK'
systemd-run --unit=probe-udp --collect socat -v udp-l:443,fork,reuseaddr system:'echo PROBE-UDP-OK'
ufw allow 443/tcp comment 'diag probe' && ufw allow 443/udp comment 'diag probe'
```

Убрать после замеров, иначе лишние открытые порты останутся висеть:

```bash
systemctl stop probe-tcp probe-udp
ufw delete allow 443/tcp && ufw delete allow 443/udp
```

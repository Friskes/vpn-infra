## Чтобы потом не переснимать

- **Замазать всё своё**: адреса серверов, домены, ссылки `vless://`, `slipnet://`,
  QR-коды (в них зашит рабочий ключ), имена клиентов, публичные ключи, IMEI и
  номер телефона в шторке Android.
- **Светлая тема** — на ней читаемо и в тёмном оформлении GitHub, наоборот не всегда.
- **Ширина 1200–1600 px**, PNG. Окно целиком не нужно — только та часть, о которой речь.
- **Клипы**: GIF или MP4 до 5 МБ, иначе GitHub долго тянет страницу. Терминал —
  крупным шрифтом, курсор видно.
- **Телефон**: снимать в вертикали, обрезать до содержимого экрана.

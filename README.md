# vpn-infra

Свой VPN-сервер за пять шагов: WireGuard и Reality (обход DPI), по желанию — DNS-туннель
против белых списков мобильных операторов и свой сервер RustDesk. Разворачивается с вашего
компьютера на любой дешёвый VPS, без чужих панелей и облаков.

## Что понадобится

- **VPS**: хватит самого дешёвого — 1 ядро, 1 ГБ памяти, Ubuntu 24.04 или Debian 12,
  выделенный IPv4. Где брать — [HOSTING.md](HOSTING.md).
- **Компьютер** с Windows 10/11 или Linux. На Windows всё работает внутри WSL — встроенного
  в Windows Linux, он ставится одной командой в шаге 1. macOS не проверялся.

## Установка

### 1. Подготовить компьютер

**Windows**: PowerShell от имени администратора, затем перезагрузка:

```powershell
wsl --install -d Ubuntu-24.04
```

После перезагрузки откройте «Пуск» → Ubuntu. При первом запуске она попросит придумать имя
пользователя и пароль — этот же пароль спросит `sudo` в следующей команде. Символы пароля
не отображаются, так и должно быть. Все команды ниже выполняются в этом окне.

**Ubuntu, Debian и WSL**:

```bash
sudo apt update && sudo apt install -y git make python3-venv
```

### 2. Скачать проект

```bash
git clone https://github.com/Friskes/vpn-infra.git ~/vpn-infra
cd ~/vpn-infra
make init
```

`make init` ставит Ansible внутрь проекта, создаёт ssh-ключ и случайные пароли и печатает
публичный ключ — строку вида `ssh-ed25519 AAAA… vpn-infra`. В WSL ключ сразу попадает в
буфер обмена Windows.

В новом окне Ubuntu сначала перейдите в проект: `cd ~/vpn-infra`.

### 3. Взять сервер

Закажите VPS и при создании вставьте ключ в поле SSH-ключа. Адрес сервера придёт в письме
и появится в панели хостера. Если вы в России, сразу проверьте его: часть адресов хостеров
уже заблокирована, и на таком сервере VPN работать не будет. Здесь и дальше вместо
`203.0.113.10` подставьте свой адрес:

```bash
python3 tools/measure/ru-reach.py 203.0.113.10
```

- `PASS` — адрес годится.
- `fail` и `DE 0/2` — не ответил даже контроль из Германии: сервер ещё загружается,
  повторите через пару минут.
- `fail` и `DE 2/2` — адрес заблокирован. Удалите сервер и возьмите другой: при почасовой
  оплате попытка стоит копейки. Подробнее — [HOSTING.md](HOSTING.md#проверить-адрес-до-деплоя).

### 4. Развернуть

```bash
make new-host NAME=vpn1 IP=203.0.113.10
make deploy
```

Ключ при заказе не вставили — между этими командами выполните `make ssh-key`: он один раз
спросит root-пароль из письма хостера. `make deploy` идёт 5–10 минут, окно не закрывайте.
Успех — строка `failed=0` в самом конце. Оборвалось с ошибкой — запустите `make deploy`
ещё раз, готовое он не переделывает.

### 5. Подключиться

```bash
make admin
```

<!-- media: make-admin.png — вывод make admin с замазанными паролями -->

Команда печатает адреса и пароли админок. Открывайте их в обычном браузере, пока окно
с `make admin` открыто:

- **WireGuard**: в wg-easy «Создать» → имя → «Создать». У клиента кнопки «Показать QR-код»
  для телефона и «Скачать конфигурацию» для компьютера.
- **Reality**: в 3x-ui один раз заведите вход по [PROXY.md](PROXY.md#завести-вход), дальше
  каждому человеку — свой клиент со ссылкой и QR.
- **AmneziaWG**, если включён: в его панели так же, как в wg-easy, но клиенты свои.

Какие приложения ставить на телефон и компьютер — [CLIENTS.md](CLIENTS.md).

Сохраните копию `keys/vpn-infra` и `.vault-key` вне компьютера, например в менеджере
паролей: без первого на сервер не зайти, без второго не расшифровать пароли. В WSL папку
проекта откроет в Проводнике команда `explorer.exe .`.

## Что ещё можно

| Нужно | Как |
|---|---|
| Интернет у мобильного оператора работает только по белому списку | DNS-туннель, нужен свой домен — [TUNNEL.md](TUNNEL.md) |
| Провайдер рвёт WireGuard сразу после подключения | AmneziaWG рядом с обычным — [SERVER.md](SERVER.md#amneziawg) |
| Свой сервер удалённого доступа RustDesk | `rustdesk_enabled: true` в `host_vars/vpn1/vars.yaml`, затем `make deploy` |
| Переезжать на другой сервер, не трогая настройки у людей | подключать клиентов по домену — [HOSTING.md](HOSTING.md#домен-нужен-не-всем) |
| В VPN пускать только нужные сервисы, остальное напрямую | [vpn-configurator](https://github.com/Friskes/vpn-configurator) |
| Второй сервер, бэкап, переезд при блокировке | [SERVER.md](SERVER.md) |
| Зайти на сервер | `make ssh`; все команды — `make help` |
